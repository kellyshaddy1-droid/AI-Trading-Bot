# 🤖 AI Trading Bot with Streamlit Dashboard

An automated algorithmic trading bot that connects to MetaTrader 5 (MT5), uses a Machine Learning model to predict market movements, and executes trades via a web dashboard.

## ⚠️ Prerequisites
* **Windows OS only** (MetaTrader 5 Python library requires Windows).
* **MetaTrader 5** desktop app installed and logged into a Demo account.
* **Python 3.10+** installed.
